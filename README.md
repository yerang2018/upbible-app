## Mac과 아이폰에서 실행하기

1. 아이폰의 App Store에서 **Expo Go**를 설치합니다.
2. Mac과 아이폰을 같은 와이파이에 연결합니다.
3. Mac에서 `command + 스페이스`를 누르고 `터미널`을 검색해 실행합니다.
4. 아래 두 줄을 터미널에 그대로 붙여 넣고 엔터를 누릅니다.

```sh
cd '/Users/cheon-yerang/Documents/ChatGPT/창업/malsseum-feed'
npm start
```

5. 터미널에 나타난 QR 코드를 아이폰의 기본 **카메라** 앱으로 비춥니다.
6. Expo Go로 열기 배너를 누릅니다. 로컬 네트워크 접근을 묻는 경우 허용합니다.
   모바일 앱은 로그인 후 읽기 화면으로 이동합니다. Expo Go에서는 네이버·카카오 로그인을 확인할 수 없으므로, 실제 로그인과 읽기 화면 확인은 아래 독립 실행 앱 또는 개발 빌드에서 진행합니다.
7. 창세기 1장 1절이 보이는지 확인하고 위로 넘겨 2절로 이동합니다. 로그아웃 상태에서는 먼저 네이버 또는 카카오로 로그인합니다.
8. 쇼츠 화면 위쪽 **크기가 다른 가·가·가**에서 글자 크기를 고릅니다. 1·2·3은 22·26·30 크기로 고정됩니다. 기존 4단계 선택은 3단계로 전환됩니다.
   글자 크기를 바꾸면 성경 본문만 바뀌고 버튼·설명·입력창·MY·하단 탭 크기는 고정됩니다.
   구절이 길어져도 글자를 축소하지 않습니다. 한 화면에 맞지 않으면 옆으로 넘겨 이어 읽습니다.
   맨 위의 나뉜 막대가 현재 읽는 부분을 표시하며, 막대를 눌러 해당 부분으로 이동할 수도 있습니다. 자동으로 넘어가지 않습니다.
   오른쪽 위 **성경 검색**에서 책 이름이나 초성(예: `ㅊ` → 창세기·출애굽기)을 입력하고 책·장·절을 선택해 이동할 수 있습니다.
9. 왼쪽 아래 **창세기**를 누르면 책·장·절을 골라 바로 이동합니다.
   구약·신약 탭으로 나누어 66권 전체에서 선택하며, 책 → 장 → 절 단계와 뒤로 가기로 이동합니다. 본문 한 번 터치로 창이 열리지 않으며 두 번 터치하면 좋아요를 설정하거나 취소합니다.
   선택창 위쪽 막대 영역을 아래로 끌면 창이 닫힙니다. 짧게 끌면 원위치로 돌아옵니다.
10. 오른쪽에는 하트(좋아요), 댓글, 책갈피(저장), 공유를 표시합니다. 좋아요와 저장은 별개입니다.
    댓글은 기기에 저장하며 작성·삭제할 수 있습니다. 로그인 후 수동 동기화하면 본인 계정에도 저장합니다. 다른 사용자에게 공개되지는 않습니다.
11. MY에서 저장 또는 좋아요 목록을 열고 구절을 누르면 쇼츠의 그 위치로 이동합니다.
12. 공유를 누르면 출처가 포함된 이미지 미리보기가 열립니다. 아이폰·안드로이드에서는
    **이미지로 공유하기**를 눌러 휴대폰 기본 공유 창을 엽니다. 브라우저 미리보기에서는 내용 공유를 제공합니다.
13. 앱을 다시 열어 위치·좋아요·저장·글자 크기가 유지되는지도 확인합니다.

실행하는 동안 Mac과 터미널 창을 켜 둡니다. 종료하려면 터미널에서 `control + C`를 누릅니다.
이미 실행 중인 개발 서버가 있다는 메시지가 보이면, 기존 QR 코드를 사용하거나
메시지에서 제안하는 다른 포트 사용을 선택하시면 됩니다.

Expo Go에서 SDK 버전이 맞지 않는다는 오류가 나면 오류 내용을 그대로 알려 주세요.
아이폰에 설치된 Expo Go와 맞도록 프로젝트는 SDK 58을 사용합니다.
개발 중 첫 실행은 Mac의 개발 서버에 연결해야 합니다. 완성 앱의 오프라인 기능과는 구분됩니다.

## 전체 성경 적용 상태

확정된 읽기 디자인과 글자 크기·가로 분할을 성경 66권 전체에 적용했습니다.
책·장별 절 수와 고정 원본 일치, 책 사이 이동 및 전체 구절 분할을 자동 검사합니다.
본문은 포함된 나눔명조의 문자 폭으로 줄을 나눈 뒤 한 줄씩 표시합니다. 글자 크기와 화면 크기가 바뀌면 다시 배치합니다.
`node scripts/build-font-metrics.mjs`로 현재 글꼴·본문의 문자 폭을 재생성할 수 있습니다.
대한성서공회 정본 전체와 단어별로 대조한 것은 아닙니다.
아이폰에서 새 책 선택·이동, 긴 구절 넘김과 기존 기록 유지를 확인해야 합니다.

출처를 확인하기 전에는 성경 본문을 기억으로 쓰거나 다른 번역본으로 대체하지 않습니다.
발견 탭의 해설 칸에는 감수된 내용이 들어오기 전까지 `준비 중`만 표시합니다.
계정 기능과 공개 웹 배포의 현재 상태는 이 문서 맨 위를 참고하세요. 결제·구독은 현재 단계에 포함하지 않습니다.

데이터는 이미 포함되어 있어 다시 내려받지 않아도 됩니다.
같은 원본에서 재현하려면 터미널의 프로젝트 폴더에서 `npm run bible:import`를 실행합니다.
인터넷 연결이 필요한 것은 이 개발용 다시 가져오기 명령입니다. 앱의 본문·글꼴·기록에는
읽기에 외부 데이터 요청이 필요하지 않습니다. 개발 전용 로그인 테스트를 누르면 Supabase와 네이버에 인증을 요청합니다. Expo Go의 개발 서버 연결은 필요하며, 네이버 로그인 검사는 Expo Go 대신 별도 개발 빌드가 필요합니다.

네이버 로그인 준비·빌드 상태는 `docs/release/로그인_구현_준비.md`를 참고합니다. 개발 빌드의 Mac 서버는 `npx expo start --dev-client`로 실행합니다. 사용자 승인 후 Android 개발 빌드가 완료되었으며 실제 휴대폰 로그인 확인이 남아 있습니다.
