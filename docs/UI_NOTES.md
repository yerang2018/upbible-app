# 시제품 UI 결정

2026-11-06 사용자 수정 요청을 반영했습니다.

- 적용 범위: 창세기 전체 50장·1,533절. 원본과 기존 기록은 유지합니다.
- 아래 탐색: 쇼츠 / MY 두 탭. 기존 4개 탭 기획보다 이번 요청을 우선합니다.
- 쇼츠 상단 왼쪽에 글자 크기 1·2·3, 오른쪽에 현재 책·장·절과 바로 이동 버튼을 배치합니다. 4단계는 제거했습니다.
- 글자 크기는 **쇼츠에서 직접 변경**합니다. MY의 설정으로 보내지 않습니다.
- 글자 크기는 22·26·30으로 고정합니다. 구절 길이·화면 크기에 따른 자동 축소는 제거했습니다.
  한 화면에 맞지 않는 긴 구절은 실제 렌더링 높이를 확인하여 어절 경계에서 나눕니다. 가로로 넘겨 이어 읽으며 세로 본문 스크롤은 사용하지 않습니다.
- 긴 구절에는 맨 위에 인스타그램 스토리 형태의 분할 진행 막대를 표시합니다. 각 막대는 같은 구절의 한 부분이며 가로 넘김에 맞춰 갱신됩니다. 막대를 눌러 이동할 수 있고 자동 넘김은 없습니다. 한 화면에 맞는 구절에는 막대를 표시하지 않습니다.
- 본문은 상하·좌우 동일한 여백으로 쇼츠 읽기 영역의 정중앙에 둡니다. 버튼 영역 높이로 본문이 위로 밀리지 않게 합니다.
- 오른쪽 세로 동작: 하트(좋아요) / 댓글 / 책갈피(저장) / 공유. 화면 높이와 관계없이 세로 배치를 유지합니다.
- 오른쪽 동작 버튼은 원형 배경·테두리 없이 아이콘과 이름만 표시합니다. 아이콘 영역 48, 아이콘 28, 이름 12 및 기존 터치 영역을 유지합니다. 본문은 좌우 같은 여백으로 중앙을 유지합니다.
- 댓글 창에서 구절별 댓글 작성·삭제를 지원하며 현재 기기에만 저장합니다. 댓글 개수도 해당 기기의 기록입니다.
- 채널명 위치: 읽고 있는 책 이름(현재 창세기). 아래에 실제 장·절 표시, 누르면 책·장·절 선택창을 엽니다.
- 바로 이동은 책 → 장 → 절 선택 후 이동하는 방식입니다. 창세기 전체를 선택할 수 있으며 문맥·MY 목록도 동일한 범위를 사용합니다.
- 최신 사용자 결정: 댓글 기능은 그대로 유지하고, 전체 데이터 검수와 출시 준비는 나중에 진행합니다. 차별화 기능은 아직 아이디어 검토 단계입니다.
- 별도의 쇼츠 제목과 구독·렌즈·트렌드·리믹스는 넣지 않습니다.
- 미색·남색·나눔명조와 직접 작성한 아이콘을 유지합니다. 참고 이미지의 로고·사진·영상은 사용하지 않습니다.
- 본문과 공유 카드에는 출처를 유지합니다. 공유는 사용자가 휴대폰 기본 공유 창에서 대상을 선택합니다.
- 이전 버전의 저장 목록과 읽던 위치는 같은 저장 키에서 이어받습니다.

## 이번 변경 확인

- 타입 검사·린트·도메인 테스트 10개·창세기 데이터 검사 통과.
- 휴대폰 크기의 웹 미리보기에서 긴 구절의 가로 스크롤·상단 막대 갱신·막대 선택 이동 확인.
- 작은 화면의 글자 크기 1·2·3에서 분할 본문 높이가 읽기 영역 안에 들어오는지 확인.
- 창세기 50장 26절 바로 이동, 해당 구절 저장·MY 목록에서 다시 열기 확인. 확인용 저장은 취소했습니다.
- 실제 아이폰·안드로이드의 가로/세로 제스처 구분과 화면 배치는 별도 확인이 필요합니다.
