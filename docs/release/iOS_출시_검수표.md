# 업바이블 iOS 출시 검수표

기준: 2026-11-11. 체크되지 않은 항목은 아직 완료되지 않았습니다.

## 현재 자료로 확인한 내용

- [x] 앱 이름 업바이블 및 11번 시안을 바탕으로 다듬은 아이콘 설정.
- [x] 성경 데이터 구조 검사: 66권, 1,189장, 31,103개 항목. 이는 정본과의 전수 대조를 의미하지 않음.
- [x] 타입 검사, 코드 검사, 자동 테스트 19개 통과 및 iOS 코드 묶음 생성. 서명된 iOS 앱 테스트는 아님.
- [x] 문의처와 개인정보 안내를 앱 내 MY 화면에 추가하고 웹 미리보기로 확인.
- [x] 대한성서공회 공식 안내에서 성경전서 개역한글판의 저작재산권 보호기간 소멸일을 확인. 원본과의 동일성 및 출처 표시는 별도 확인 필요.

## 앱과 기기 검수

- [ ] 배포용 iOS 앱 생성 후 실제 iPhone에 설치하고 시작·재시작 확인.
- [ ] 짧은 구절, 긴 구절, 화면이 작은 기기에서 세로 넘김과 긴 구절 가로 넘김, 문장 끝 누락 여부 확인.
- [ ] 글자 크기 1–3단계에서 본문·버튼·검색·선택창이 읽히고 잘리지 않는지 확인.
- [ ] 책 이름과 초성 검색, 구약·신약 선택, 장·절 이동 및 선택창 끌어 닫기 확인.
- [ ] 좋아요·저장·댓글 작성 및 삭제, 앱 재실행 후 기록 유지 확인.
- [ ] 공유 이미지 내용과 실제 공유 동작, 기기 백업 및 복원 동작 확인.
- [ ] iPad 지원 여부 결정. 지원한다면 실제 iPad 화면과 회전·레이아웃도 확인.
- [ ] 사용자가 이해하기 쉬운 글자 크기와 터치 영역, VoiceOver 접근성 확인.
- [ ] 최종 빌드에 포함된 모든 SDK의 개인정보 처리와 필수 개인정보 매니페스트 확인.

## 스토어 등록과 공개

- [ ] Apple Developer Program 가입 후 개발자 명의, 앱 ID 사용 가능 여부 확인.
- [ ] 이름과 로고의 App Store 검색 및 상표 확인. 검색만으로 상표 사용 가능을 확정할 수 없음.
- [ ] 개인정보처리방침의 운영자 정보, 시행일 및 최종 빌드 데이터 처리를 검토하고 공개 URL 게시. 앱 안에서도 해당 정책에 접근할 수 있도록 확인.
- [ ] 지원 페이지를 공개하고 실제 문의 이메일 수신 가능 여부 확인.
- [ ] 실제 앱에서 iPhone 스크린샷 촬영. iPad 지원 시 iPad 13인치 스크린샷도 준비. 애플의 현재 규격을 제출 직전 재확인.
- [ ] 가격·출시 국가, 연령 등급, 개인정보 신고, 암호화 수출 규정 항목을 최종 앱과 일치시켜 입력.
- [ ] 성경 데이터의 원문 전수 대조 여부와 오탈자 검수 범위를 명확히 하고, 관련 출처 및 라이선스 고지를 확인.
- [ ] TestFlight에서 최종 버전 점검 후 제출.
