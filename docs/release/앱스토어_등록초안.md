# 업바이블 앱스토어 등록 초안

## 앱 이름
업바이블

## 소개 문구 초안
한 절씩 넘기며 성경을 읽어 보세요. 업바이블은 개역한글 성경을 책·장·절별로 찾아 읽을 수 있는 앱입니다.

- 위아래로 넘기며 한 절씩 읽기
- 길이가 긴 구절은 옆으로 넘겨 이어 읽기
- 책 이름이나 초성으로 찾고 원하는 장·절로 이동하기
- 글자 크기 조절하기
- 마음에 남은 구절을 좋아요하거나 저장하기
- 구절별 개인 댓글 기록하기
- 네이버·카카오 로그인 후 기록 수동 동기화하기
- 성경 구절과 출처가 담긴 이미지 공유하기

성경 본문: 성경전서 개역한글판. 구절별 댓글과 저장 기록은 기기에 보관되며, 로그인 후 수동 동기화하면 본인 계정에도 저장할 수 있습니다. 다른 사용자에게 공개되지 않습니다. 로그인 기능은 제공자 검수와 배포용 앱의 실제 검증 후 최종 소개에 포함합니다.
