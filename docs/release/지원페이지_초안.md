오류를 알려 주실 때 사용 중인 기기, iOS 버전, 문제가 발생한 화면과 상황을 함께 적어 주시면 확인에 도움이 됩니다. 성경 구절의 오류는 책 이름과 장·절을 함께 알려 주세요. 비밀번호나 인증번호 등 민감한 정보는 보내지 마세요.

## 자주 묻는 질문

**원하는 구절은 어떻게 찾나요?**  
화면 위쪽의 성경 검색에서 책 이름이나 초성을 입력하고 책과 장·절을 선택하세요.

**긴 구절의 뒷부분은 어떻게 읽나요?**  
구절이 여러 화면으로 나뉜 경우 본문을 옆으로 넘겨 이어서 읽을 수 있습니다.

**댓글은 다른 사람에게 보이나요?**  
댓글은 현재 기기에 저장되며, 로그인 후 수동 동기화하면 본인 계정에도 저장할 수 있습니다. 다른 사용자에게 공개되지 않습니다.

**기기를 바꾸면 저장 기록도 옮겨지나요?**  
기존 기기의 내 계정에서 기록 동기화를 누른 뒤, 새 기기에서도 같은 로그인 방법과 계정으로 로그인하고 동기화를 누르세요. 자동 동기화는 아닙니다. 기록이 다르면 사용할 기록을 선택합니다.

**계정을 삭제하려면 어떻게 하나요?**  
내 계정 → 회원 탈퇴 → 계정과 서버 기록 삭제 확인으로 진행합니다. 앱을 설치하지 않은 경우 공개 웹의 `/delete-account`에서 시작할 수 있습니다. 해당 경로는 배포 완료 후 스토어에 등록합니다.
