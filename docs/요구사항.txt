# Codex에 붙여넣을 프롬프트 (v3, 2026-11-04: Scroll The Bible 화면 구조를 법적 문제 없는 선에서 참고)

아래 "----" 사이를 통째로 복사해서 Codex에 붙여넣으세요.

----

너는 지금부터 코딩 경험이 전혀 없는 창업자와 함께 모바일 앱을 만드는 시니어 개발자야. 아래 규칙과 기획을 끝까지 읽고, **1단계만** 먼저 만들어 줘.

## 나에 대해, 그리고 일하는 방식
- 나는 코딩을 해 본 적이 없어. 터미널 명령어를 실행해야 하면 "어디에 무엇을 붙여넣고 엔터를 누르면 된다"까지 한국어로 하나씩 알려 줘.
- 한 번에 많이 만들지 말고, 내가 휴대폰에서 직접 확인할 수 있는 작은 단위로 나눠서 진행해 줘. 각 단계가 끝날 때마다 "지금 휴대폰에서 이걸 눌러 보면 이렇게 보여야 정상"이라고 확인 방법을 알려 줘.
- 에러가 나면 내가 에러 메시지를 그대로 붙여넣을 테니, 원인을 쉬운 말로 설명하고 고쳐 줘.
- 코드에 들어가는 설명 주석과 화면 문구는 모두 한국어로 해 줘.
- 비밀번호, API 키 같은 비밀값은 절대 앱 코드 안에 직접 넣지 마.

## 앱 한 줄 소개
"쇼츠 대신 넘기는 말씀". 틱톡·릴스처럼 화면을 위로 넘길 때마다 성경 구절이 한 절씩 전체 화면 카드로 나오는 앱이야. 기존 성경 앱을 대체하는 게 아니라, 심심할 때 숏폼 대신 여는 앱이야.

## 기술 선택 (이대로 해 줘)
- Expo(React Native) + TypeScript. 아이폰과 안드로이드를 둘 다 지원해 줘(한국은 안드로이드 사용자가 많아).
- 처음에는 내 휴대폰의 Expo Go 앱으로 바로 확인할 수 있게 만들어 줘.
- 1단계는 서버, 로그인, 결제 없이 **인터넷 없이도 동작**하게 만들어 줘. 저장한 구절, 연속 사용일, 설정은 기기 안(AsyncStorage)에 저장해.

## 성경 본문 (아주 중요)
- 반드시 **「성경전서 개역한글판」**만 사용해. 저작재산권 보호기간이 끝난 번역본이라 무료로 쓸 수 있어.
- **개역개정, 새번역, 쉬운성경 등은 대한성서공회 허락이 필요하니 절대 넣지 마.**
- 성경 구절을 네가 기억으로 직접 쓰지 마. 틀린 구절이 들어가면 안 돼. 공개된 개역한글 데이터 파일(JSON 또는 텍스트)을 구해서 앱 안에 넣는 방법을 알려 주고, 그 파일을 읽어서 쓰는 코드를 짜 줘.
- 데이터를 넣은 뒤에는 66권이 모두 있는지, 책별 장 수가 맞는지, 전체 절 수가 약 3만 1천 절인지 확인하는 검사 스크립트도 만들어 줘.
- 모든 카드와 공유 이미지 아래에 "성경전서 개역한글판"이라고 출처를 작게 표기해 줘.

## 디자인 방향 (가장 중요)
미국 앱 "Scroll The Bible"의 화면 구조와 분위기를 참고해서 만들어 줘. 단, **기존 앱과 법적인 문제(저작권, 상표권, 부정경쟁, 앱스토어 심사 거절)가 생기지 않는 선에서만** 참고해야 해. 아래 규칙을 반드시 지켜 줘.

**참고해도 되는 것 (아이디어·기능·흔한 배치)**
- 한 절씩 세로로 넘기는 방식, 탭 구성, 오른쪽 하트·공유 버튼, 책·장·절 돌림판처럼 여러 앱이 흔히 쓰는 화면 배치와 기능.
- 미니멀하고 차분한 분위기.

**절대 가져오면 안 되는 것 (표현)**
- 그 앱의 이름, 이름을 번역하거나 비슷하게 바꾼 이름(예: "스크롤 더 바이블", "성경 스크롤").
- 로고, 앱 아이콘, 가시면류관 그림, 사진, 일러스트 등 모든 이미지.
- 화면 문구, 광고 문구, 결제 화면 문구를 번역하거나 살짝 바꿔 쓰는 것. 모든 문구는 한국어로 새로 써.
- 그 앱의 스크린샷을 앱 안이나 홍보물에 쓰는 것.

**전체가 똑같아 보이지 않게 할 것**
- 원조 스크린샷과 나란히 놓았을 때 "같은 회사 앱이네"라는 말이 나오면 안 돼. 애플 심사 지침 4.1(다른 인기 앱 베끼기 금지)에 걸리지 않도록, 아래 "우리만의 표시"를 반드시 넣어 줘.
- 만들다가 원조와 너무 비슷해지는 부분이 있으면 나에게 먼저 알려 주고, 다르게 바꿀 방법을 제안해 줘.

**우리만의 표시**
- 배경: 순백이 아니라 **따뜻한 미색(한지 느낌, 예: #F7F3EA)**. 다크 모드는 따뜻한 짙은 회색.
- 포인트 색 하나: **짙은 남색(예: #1F2A44)**. 주요 버튼, 선택된 탭, 진행 막대에 사용.
- 아이콘·그림: 우리가 새로 만든 단순한 선 아이콘(예: 빛이 퍼지는 모양, 등불, 펼친 두루마리). 남이 만든 그림을 쓰지 말고, 무료 아이콘을 쓸 때는 상업적 이용이 허용된 라이선스인지 확인하고 출처를 기록해.

**전체 분위기**
- 미색 배경, 짙은 글씨, 회색 보조 글씨, 포인트 색은 남색 하나. 차분하고 미니멀한 디자인.
- 성경 본문과 제목은 **명조(세리프) 계열 한글 글꼴**(예: Noto Serif KR 또는 나눔명조), 버튼·작은 글씨는 고딕 계열.
- 장식은 최소한으로. 카드 모서리는 둥글게, 그림자는 아주 옅게.

**탭 4개 (화면 맨 아래, 아이콘 + 작은 글씨)**
보관함(하트) / 발견(반짝이) / 검색(돋보기) / 성경(펼친 책). 앱을 켜면 "성경" 탭이 먼저 나와.

## 1단계 기능 (지금 만들 것)
1. **성경 탭 = 세로 스와이프 피드 (메인 화면)**
   - 성경을 **장 단위로 순서대로** 한 절씩 넘겨 읽는 화면이야. 처음 켜면 요한복음 3장 16절부터 시작.
   - 한 화면에 한 절. 위로 넘기면 다음 절, 장이 끝나면 다음 장 1절로 자연스럽게 이어져. 틱톡처럼 한 장씩 딱 끊겨 넘어가야 해.
   - 화면 가운데 위쪽에 작은 정사각형 카드 안에 우리가 만든 단순한 선 아이콘(예: 빛이 퍼지는 모양)을 하나 두고, 그 아래에 본문을 크게 명조체로 “따옴표”와 함께 가운데 정렬. 그 아래 회색으로 "요한복음 3:16".
   - **왼쪽 가장자리**에 얇은 세로 진행 막대: 지금 장에서 몇 번째 절인지 위치를 점으로 보여 주고 절 번호를 작게 표시.
   - **왼쪽 위**: 검색 아이콘 버튼, 번역본 칩("개역한글"). **오른쪽 위**: "요한복음 3 ⌄" 칩 — 누르면 책·장을 고르는 창이 열려.
   - **오른쪽 아래**: 동그란 버튼 세로로 하트(저장), 말풍선(묵상 메모), 공유.
   - 너무 긴 절도 잘리지 않게 글자 크기를 자동으로 줄여 줘.
   - 마지막으로 읽던 위치를 기억해서 다음에 켜면 거기서 이어서 시작.
2. **구절 누르면 앞뒤 문맥 보기**: 본문을 누르면 아래에서 시트가 올라와 앞뒤 3절을 보여 줘. (나중에 여기에 "쉽게 풀어주기" 같은 유료 공부 기능이 들어갈 자리야.)
3. **발견 탭**: 많이 사랑받는 구절(요 3:16, 시 23:1, 시 34:18, 빌 4:13, 사 41:10, 렘 29:11, 롬 8:28 등 50개 정도)을 무작위로 한 장씩 넘겨 보는 카드 피드.
   - 카드 구성: 맨 위 작은 회색 주제 칩(예: "하나님의 가까우심"), 큰 명조 제목 "시편 34:18", 기울임체 본문, 그 아래 "이 말씀은요" 섹션과 연한 박스의 "한 걸음 더" 섹션, 관련 구절 칩 2개, 맨 아래 저장·메모·공유 아이콘.
   - 1단계에서는 "이 말씀은요"와 "한 걸음 더" 칸에 **"준비 중"이라고만** 표시해 줘. 내용은 나중에 목회자 감수를 받은 글로 내가 직접 채울 거야. 네가 해석을 지어내서 넣지 마.
4. **검색 탭**: 위에 "구절 검색" 제목, 책 / 장 / 절을 고르는 돌림판(휠) 선택기 세 칸, 그 아래 검은색 둥근 버튼 "이 구절 보기". 누르면 성경 탭 피드가 그 구절로 이동. 단어로 본문을 검색하는 기능도 함께.
5. **보관함 탭**: 저장한 구절과 묵상 메모 목록. 맨 아래에 설정(테마, 글자 크기 4단계, 알림 시간) 들어가는 버튼.
6. **공유**: 구절을 미색 배경 명조체 이미지 카드로 만들어 카카오톡·인스타그램 등으로 공유(휴대폰 기본 공유 창). 이미지 아래에 작게 앱 이름과 "성경전서 개역한글판".
7. **매일 말씀 알림**: 사용자가 고른 시간(기본 오전 7시)에 한 구절을 알림으로 보내고, 누르면 그 구절이 열리게.
8. **연속 사용일**: 하루에 한 번 이상 열면 연속일이 올라가. 성경 탭 위쪽에 작게 "🔥 5일째".
9. **첫 실행 소개 화면** (미색 배경, 가운데 명조체 큰 문장, 아래 "위로 올려 계속 ›"):
   - "무심코 쇼츠를 넘기던 그 손가락으로," / 작은 글씨 "오늘은 말씀 한 절을 넘겨 볼까요?"
   - "하루 한 절이면 충분해요. 매일 같은 시간에 말씀을 보내 드릴게요."
   - 알림 시간 고르기.
   (문구는 나중에 고치기 쉽게 한 파일에 모아 둬.)

## 2단계 이후 (지금은 만들지 말고, 나중에 붙이기 쉽게 구조만 잡아 둬)
- 구절을 누르면 "쉽게 풀어주기", "원어 뜻", "관련 구절"을 보여 주는 유료 기능. 풀이는 처음엔 많이 읽히는 구절 300개에 대해 미리 만들어 두고 목회자 감수를 받은 내용만 넣을 예정이야. 앱에서 AI를 직접 부르지 않아.
- 1주 무료체험 후 월 4,900원 / 연 29,000원 구독(RevenueCat 사용 예정). 구독료 일부는 선교·구호 단체에 기부.
- 교회 코드 입력 기능: 교회가 그 주 설교 본문 구절들을 정하면 성도들 피드에 먼저 나오게 하는 기능.

## 시작 순서
1. 먼저 내 컴퓨터에 무엇을 설치해야 하는지(Node.js 등) 확인하는 방법부터 알려 줘. (내 컴퓨터 운영체제를 먼저 물어봐 줘.)
2. 프로젝트를 만들고 Expo Go로 빈 화면이 휴대폰에 뜨는 것까지 확인.
3. 개역한글 데이터 넣기 + 검사 스크립트.
4. 그다음 위 1단계 기능을 1번부터 순서대로.

이해했으면 내가 확인해야 할 것만 짧게 물어보고 시작해 줘.
